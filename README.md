# BLOS Enterprise System · BES Portal v2.1.0

Portal ejecutivo de Best Linen para gobierno, operación, información y mejora continua.

## Alcance publicado

- Acceso protegido mediante Supabase Auth, cambio obligatorio de contraseña y MFA.
- Centro de Arquitectura BES con 14 pilares, 22 carpetas estándar y línea de mando.
- Cadena de Valor BES con diez nodos: Gobierno, Source, Materia Prima, Telas e Insumos, Producción, Talleres, Producto Terminado, Racks, Almacén Central y Logística.
- Universidad Best Linen, modelo de certificación y Plan Carrera de 12 niveles.
- Mapa de procesos transversales y gobierno de información Odoo ↔ BL RACKS.
- Expansión organizacional con nueve puestos operativos y de control.
- Estándar universal de documentos controlados con diez secciones obligatorias.
- Biblioteca ejecutiva visible con manual maestro, presentación y expediente de puestos.
- Agenda, persistencia local, importación/exportación JSON, auditoría y diseño responsivo.
